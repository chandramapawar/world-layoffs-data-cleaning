World Layoffs Data Cleaning Using SQL
Project Overview
This project focuses on cleaning and preparing a world layoffs dataset using SQL in MySQL Workbench.
Tools Used
- MySQL
- MySQL Workbench
Data Cleaning Steps
1. Removed duplicate records using ROW_NUMBER().
2. Standardised inconsistent data.
3. Handled NULL and blank values.
4. Populated missing industry values using self joins.
5. Removed unnecessary columns and rows.
SQL Concepts Used
- CTEs
- Window Functions
- Self Joins
- UPDATE and DELETE statements
- Subqueries
Outcome
Prepared a cleaner dataset suitable for further analysis.
